# SkillSwap Homepage

A responsive, modern SkillSwap landing page built with plain HTML, CSS and JavaScript.

## Run
1. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser.
3. For development, use VS Code + Live Server if available.

## Included
- Responsive desktop/tablet/mobile UI
- Sticky navigation + mobile menu
- Hero section with AI match card
- Social proof statistics
- 4-step How It Works section
- AI matching dashboard
- In-person / virtual learning cards
- CTA and footer
- Smooth scrolling and small interactions
